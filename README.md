# Electric Vehicle (EV) Analysis | Tableau

## 📌 Project Overview
This project focuses on analyzing Electric Vehicle (EV) data using Tableau to understand EV adoption trends, vehicle types, manufacturer performance, and geographical distribution.
The dashboard presents key insights through interactive visualizations, helping users explore electric vehicle market trends and patterns.

## 🎯 Project Objectives
* Analyze the distribution of Battery Electric Vehicles (BEVs) and Plug-in Hybrid Electric Vehicles (PHEVs).
* Identify leading EV manufacturers and popular vehicle models.
* Understand EV adoption trends over the years.
* Explore the geographical distribution of electric vehicles across states.
* Build an interactive dashboard for data-driven insights.

## 🛠️ Tools & Technologies
* **Visualization Tool:** Tableau
* **Data Analysis:** Data Cleaning and Exploratory Data Analysis
* **Visualization Techniques:** Bar Charts, KPI Cards, Trend Analysis, and Interactive Filters

## 📊 Key Insights
* **150K+ Records:** Analyzed a dataset containing over 150,000 electric vehicle records.
* **77.6% BEVs:** Battery Electric Vehicles accounted for approximately 77.6% of the vehicles.
* **52.7% Tesla:** Tesla represented approximately 52.7% of the vehicles in the dataset.
* **2023 Peak:** The year 2023 recorded approximately 37.1K vehicles.
* **Average Electric Range:** The average electric range was approximately 67.83 miles.

## 📈 Dashboard Features
* Analysis of BEVs and PHEVs.
* Manufacturer-wise EV distribution.
* Year-wise vehicle adoption trends.
* State-wise geographical analysis.
* Interactive filters for EV Type, Model, State, and CAFV Eligibility.
* Top N parameter to dynamically analyze leading vehicle models.
